# Assets and tools

The game was created for Raghava Charan with AI-assisted coding and original generated artwork. AI assistance must be disclosed according to the organizer's requirements. The recovered rules make AI use conditional on organizer permission; no confirmation of that permission was present in the recovered chat.

- `public/cover.png`: original cover generated using OpenAI's built-in image-generation tool on 14 September 2026.
- `public/courtyard.png`: original courtyard generated with the same tool and date.
- Character, offerings, gates, portals, shrine silhouette, UI ornament, particles, and rangoli: drawn locally by the project's Canvas/SVG code.
- Music and sound: original synthesized notes, bell tones, and percussion in `src/audio.ts`. No sampled songs or external recordings.
- Fonts: device/system fonts and Georgia fallback. No font downloads.
- Runtime: browser Canvas, Web Audio, Pointer Events, localStorage. Build tools: Vite and TypeScript.

The small shrine is the destination, never an enemy. Moving shadows interact only with Mushak. The rangoli activity is creative game design, not a claim to reproduce a prescribed ritual.

A tiny brave ivory-grey mouse Mushak with warm ears, an amber silk scarf and a small offering bundle stands on a carved ancient stone path in the lower right foreground, looking toward a magnificently illuminated Indian temple in the upper right background. A winding luminous golden path threads through lotus pools, stone stairs, marigold garlands, banyan roots, and floating fireflies. Emerald midnight forest, teal atmospheric depth, amber illumination, painted foliage, soft volumetric beams. Dignified temple, no deity closeup. Left half dark negative space for typography added in code. No text, logos, or watermark.
